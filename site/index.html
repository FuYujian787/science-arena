假说引力 / SCIENCE ARENA

让研究假说，
经得起多学科追问。

五类角色独立评审、交叉质询，从一句假说或已有研究中识别争议，形成可回看的修改建议。使用自己的模型 API，模型输出仍需研究者核查。

下载安装

Windows 和 Mac 安装包以本仓库 Releases 实际发布文件为准。首次运行后在「模型设置」填写自己的 API Key，也可选择离线演示。

网页版与安卓

完整网页版需要独立部署 Node 后端，当前介绍页不运行科研辩论。部署至 HTTPS 后，安卓用户可通过浏览器安装到主屏幕；这属于 PWA，当前没有原生 APK。
