## Science Arena 0.2.0 预览版

由假说引力团队提供的多智能体科研假说辩论与方案修正平台。

### 下载与使用

- Windows x64：下载 EXE 安装包，或 ZIP 免安装版（解压整个目录后运行 Science Arena.exe）。无需预装 Node.js。
- Mac：请按电脑芯片选择 arm64 / x64 DMG；以本页实际存在的附件为准。
- 首次打开，在「模型设置」填写自己的 DeepSeek API Key，或 Dify 地址与 App Key。也可选择离线演示。
- 研究输入支持一句话假说与已有研究的聚焦讨论，保留争议清单、创新潜力初评、修改建议、研究方案与 Word 导出。
- 源码与网页版部署包包含 Docker Compose、HTTPS 反向代理和安卓 PWA 配置。部署网页需要自己的服务器与域名；GitHub 介绍页不执行科研辩论。

### 数据

桌面记录保存在个人应用目录；设置可用系统安全存储加密。研究内容会发送至你选择的模型服务。安装包不内置团队密钥，不包含团队私人历史、论文或比赛原始材料。

网页版使用浏览器访客凭证隔离历史和导出，个人密钥不写入会话文件；刷新后需重新输入。此预览版无跨设备账号恢复。

### 验证范围

已验证本机 Windows 打包程序窗口加载、后端启动及加密设置往返；引擎、网页全流程、Dify 模拟集成、密钥并发隔离与跨访客访问拦截均有自动检查。

Mac 构建结果以 Actions 为准，尚未进行 Mac 实机启动验收；安卓 PWA 尚未实机安装验收。不提供原生 APK。Windows 尚未在第二台干净设备完成安装验收。

本版安装包未做开发者签名，发布为预览版。模型建议与创新潜力初评仍需研究者复核，不替代导师指导、伦理审查或临床决策。

当前尚未指定开源许可证，团队保留相关权利。
